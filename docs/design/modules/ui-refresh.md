# 界面改版：灰白 + 轻浮雕 + 对局专注

把整个界面从「卡片拼装」改成一套有层次的材料：灰白基准、轻浮雕立体、对局时只留必要信息；手机上一屏装下整个棋盘，不用拖。

Closest precedent: `docs/design/modules/board-ui.md` §2（棋盘八层与棋子单字）、§5（三档断点与尺寸公式）与 `docs/design/modules/local-play.md` §5（面板三档高度表）。布局与尺寸规则都沿用，只换材料与对局页的信息取舍。

对齐：断点（≥1024 / 768–1023 / <768）、棋盘 `boardSize` 的高度优先公式、棋子传统字与红色两色——全部不动。

偏差：面板在窄屏由「占位抽屉」改成「覆盖式抽屉」，不再挤压棋盘高度；对局页默认收起着法记录。理由见 §2/§3。

Survey evidence: 已核对 `docs/requirements/xiangqi.md` §3 F4.1–F4.5 与 F5.1–F5.4、`docs/design/modules/board-ui.md` §2/§5/§6、`docs/design/modules/local-play.md` §5、`src/client/app.css`（现行变量与 `.board-fit`/`.panel` 规则）。

相关：仓库里没有设计 token 层，颜色与圆角散落在 `src/client/app.css`；本批首次把它们收成变量。

## 2. 材料（设计 token）

`src/client/app.css` 顶部收成一组变量，页面与组件只引用变量，不再写字面色值：

| 变量 | 值 | 用途 |
|---|---|---|
| `--bg` | `#f4f5f7` | 页面底 |
| `--surface` | `#fbfbfc` | 卡片、面板、抽屉 |
| `--line` | `#e2e4e8` | 分隔线与描边 |
| `--ink` | `#1f2328` | 正文 |
| `--ink-muted` | `#6b7280` | 次要信息（计时、来源、步数） |
| `--raise` | `0 1px 0 rgba(255,255,255,.9) inset, 0 1px 2px rgba(16,24,40,.06), 0 8px 24px rgba(16,24,40,.06)` | 轻浮雕：内高光 + 近层 + 远层 |
| `--radius` | `10px` | 卡片、按钮、输入框 |

- 立体**只做两层投影加一层内高光**：够看出「浮起来」，又不吃掉棋盘线条的可读性。
- 棋子保持红黑两色 + 中性描边，加一圈内阴影表现厚度；棋盘底色略暖（`#f7f2e6`），只为衬托棋子，不加纹理。
- 明令不做：木纹、皮革、金属渐变、发光描边、装饰性插画。理由：这是教学工具，马腿、河界、九宫线要一眼读准。

## 3. 对局专注

| 页 | 常驻 | 默认收起 |
|---|---|---|
| 对弈 | 棋盘、行棋方与双方计时、新局、认输 | 着法记录、记谱输入、面板其余内容、页面副标题 |
| 人机 | 同上 | 着法记录、记谱输入、难度与阵营（开局前展开一次） |

- 收起不是删除：面板顶部一个「着法」切换（`aria-expanded`），点开展开抽屉/侧栏，点收起回到专注。
- 面板在 ≥1024 与 768–1023 两档的行为不变（右侧栏 / 底抽屉），只改**默认收起**；<768 档改覆盖式抽屉（见 §4）。
- 观战、联机、棋谱、课程、练习页不在本批改动范围。

## 4. 手机一屏

现状：`<768` 上面板占 40dvh 并与棋盘争高度，加上 360px 的棋盘宽度下限，375×667 上棋盘被顶出可视区，只能滚动看。

改法两条：

1. **面板改覆盖式**：`position: fixed` 贴底，默认收起；展开时盖住棋盘下沿而不是挤走它。棋盘始终按「整个可用区」算尺寸。
2. **棋盘按高度优先**：沿用 `boardSize` 的 `min(可用宽, 可用高 × 9/10)`，只把对局页的可用高算成 `100dvh − 顶栏高`（不含面板），并禁掉对局页的纵向滚动。

可验的数：375×667 上棋盘完整、页面无纵向滚动；360 宽时格宽正好 40px，与既有下限一致；旋转后局面与选中态不丢（沿用 `ResizeObserver`）。

## 8. 风险

- 覆盖式抽屉在 iOS 上有 `dvh` 变化的抖动风险：用 `100dvh` 而非 `100vh`，并在展开时锁定背景滚动。
- 默认收起会改变既有用例的入口假设（部分用例先点面板按钮）；实施轮要逐个跑，发现依赖「面板常开」的断言就改入口，不改业务断言。
- 轻浮雕若调得重会压掉棋盘线条；棋子内阴影限在描边内 1px。
