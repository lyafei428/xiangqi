# 主题：DeepSeek 深色界面 + 浅色棋盘

界面换成深色（近黑底、蓝色强调、描边分层），棋盘保持浅色像一张纸放在深色桌面上。

Closest precedent: `docs/design/modules/ui-refresh.md`（本模块沿用它的变量层结构、对局专注结构与手机一屏几何，只换取值与分层方式）。偏离两处：①深色下阴影看不见，分层改用 1px 描边 + 面板底色一档之差，`--raise` 随之重定义；②色值按「落在浅色棋盘上」与「落在深色界面上」拆成两组，同一个 `--red` 同时当棋盘标记与面板文字会在深底上掉到 2.6:1。

Survey evidence: 已用浏览器实读 `https://chat.deepseek.com` 登录页（截图 + `getComputedStyle`）。逐层读数：

- 页面底 `rgb(21,21,23)`
- 卡面 `rgb(27,27,28)`
- 主文字 `rgb(249,250,251)`
- 次文字 `rgb(173,178,184)` 与 `rgb(129,133,140)`
- 强调蓝 `rgb(86,134,254)`
- 描边 `rgba(255,255,255,0.12)`
- 圆角：按钮 10–12px、卡片 14px；字体栈含 `Inter, system-ui, -apple-system`

对比度按 WCAG 2.1 的相对亮度与对比度公式算（`(L1+0.05)/(L2+0.05)`，sRGB 分量先线性化）。除站点实读外未查其他文档来源；公式属通行定义，不依赖具体文档版本。

## 1. 需求

需求口径在 `docs/requirements/xiangqi.md`（F5.5 视觉基准、F5.1 界面简约）。本档只记落点，不抄需求正文。

F5.5 对实现的三个约束，逐条对应到本档：分色（§2）、对比度（§3）、无图片与纹理与渐变（§7 的读数）。

## 2. 取值

同一个颜色的两种用途分开：**棋盘色**只落在浅色棋盘上，**界面文字色**落在深底上。混用会在深底上掉到 2.6:1 以下（见 §3 的「禁止组合」）。

| 变量 | 现在（浅色批） | 本批 | 用途与来源 |
|---|---|---|---|
| `--page-bg` | `#f4f5f7` | `#151517` | 页面底（DeepSeek 实测） |
| `--panel-bg` | `#fbfbfc` | `#1b1b1c` | 卡片、面板、抽屉（实测） |
| `--raise-bg` | `#fbfbfc` | `#232325` | 可按的浅面，如按钮底 |
| `--sunken-bg` | `#eef0f3` | `#101012` | 悬停与选中的凹面 |
| `--line` | `#e2e4e8` | `rgba(255,255,255,0.12)` | 分隔线与描边（实测） |
| `--text` | `#1f2328` | `#f9fafb` | 正文（实测） |
| `--muted` | `#5b6472` | `#adb2b8` | 次要文字（实测） |
| `--muted-2` | — | `#878b92` | 第三档灰：元信息、占位符。由 `#81858c` 提亮一档——原值在 `--raise-bg` 上只有 4.23:1 |
| `--accent` | `#b0742a` | `#5686FE` | 链接、描边、聚焦环（实测）。**不作填充底** |
| `--accent-strong` | `#966023` | `#3f63d8` | 填充按钮底：白字在 `#5686FE` 上只有 3.37:1，压深到 5.27:1 |
| `--on-accent` | — | `#ffffff` | 填充按钮上的字：在 `--accent-strong` 上 5.27:1 |
| `--low` | `#a12f2f` | `#ff6b6b` | 时钟低时、错误态文字 |
| `--red-text` | — | `#f27b6e` | **界面上的红方文字**（时钟、行棋方、红方标记） |
| `--black-text` | — | `#c9ced6` | **界面上的黑方文字**：深底上不能写黑字，改用中性浅色 |
| `--target-text` | — | `#4f9c74` | **界面上的提示绿文字**（课程、练习里的正确项） |
| `--radius` | `10px` | `12px` | 按钮、输入框 |
| `--radius-lg` | — | `14px` | 卡片 |
| `--board-bg` | `#f7f2e6` | 不变 | 棋盘底：它是「纸」 |
| `--board-line` | `#b9a98d` | 不变 | 盘线 |
| `--piece-face` | `#fdfcf7` | 不变 | 棋子面 |
| `--piece-edge` | `#9a9184` | 不变 | 棋子描边 |
| `--red` | `#b3261e` | 不变 | **只在棋盘上**：棋子与标记的填充 |
| `--black` | `#22262b` | 不变 | **只在棋盘上**：棋子填充 |
| `--target` | `#2f6f4f` | 不变 | **只在棋盘上**：可走点与选中框的描边与填充 |
| `--board-ink` | `#8a6a45` | `#846340` | **只在棋盘上**：河界字样。原值在盘面上 4.45:1，压深一档到 4.90:1 |
| `--raise` | 内高光 + 两层投影 | `0 0 0 1px rgba(255,255,255,.08) inset` | 深底上投影看不出来，改成内描边，分层靠线 + 底色差 |
| `--raise-flat` | 内高光 + 近层投影 | `0 0 0 1px rgba(255,255,255,.06) inset` | 同上，更轻的一档 |
| `--font-ui`、`--font-board` | — | 不变 | 字体 |

两条固定项，后续改主题时不许动：

- **棋盘色不跟着界面变深**。`--red`／`--black`／`--target` 与棋盘四色只在浅底上使用；界面上要红色或黑色文字时用 `--red-text`／`--black-text`／`--target-text`。
- **棋盘的外投影是分层手段，不是装饰**：深色桌面上要让它被读成一张纸。全站只此一处投影，卡片与按钮都不投影（`docs/requirements/xiangqi.md` F5.1 的「无装饰性元素」按此读）。

## 7. 验收

- **对比度**：`node scripts/acceptance.mjs` 打印 §3 的断言集并逐行断言 ≥ 4.5；另断言「填充按钮底不含 `--accent`」——取所有带背景色的按钮规则，检查背景值落在 `--accent-strong`。
- **无图片与渐变**：同一脚本里 grep 样式表，断言不含 `linear-gradient`／`radial-gradient`／`url(`。
- **一屏**：375×667 下棋盘完整、无元素越界（沿用 M10 的断言）。
- **实机目视**：1440 桌面（对局页收起 / 展开）与 375×667 手机各一张截图。
- 提交门见 `AGENTS.md`。

## 8. 风险

- 棋盘色与界面文字色混用是这条主题最容易被后人改坏的地方：`--red` 一旦被拿去当面板文字，对比度从 6.4 掉到 2.6。§2 的两条固定项 + §3 的禁止组合共同守这一条。
- `--muted-2` 余量最小（`--raise-bg` 上 4.59），只准用于元信息与占位符，不用于正文或按钮。
- 深色让投影失效；只换颜色不改 `--raise`／`--raise-flat`，卡片会糊成一片。
- 只做深色一套：不做 `prefers-color-scheme` 分支、不做主题开关。要浅色版本是另一批的事。
