# 主题：DeepSeek 深色界面 + 浅色棋盘

界面换成深色（近黑底、蓝色强调、描边分层），棋盘保持浅色像一张纸放在深色桌面上。

Closest precedent: `docs/design/modules/ui-refresh.md`（本模块沿用它的变量层结构、对局专注结构与手机一屏几何，只换取值与分层方式）。偏离：深色下阴影看不见，分层改用 1px 描边 + 面板底色一档之差，`--raise` 随之重定义。

Survey evidence: 已用浏览器实读 `https://chat.deepseek.com` 登录页（截图 + `getComputedStyle`）。逐层读数：

- 页面底 `rgb(21,21,23)`
- 卡面 `rgb(27,27,28)`
- 主文字 `rgb(249,250,251)`
- 次文字 `rgb(173,178,184)` 与 `rgb(129,133,140)`
- 强调蓝 `rgb(86,134,254)`
- 描边 `rgba(255,255,255,0.12)`
- 圆角：按钮 10–12px、卡片 14px；字体栈含 `Inter, system-ui, -apple-system`

## 1. 需求

需求口径归 `docs/requirements/xiangqi.md`。F5.5 需要改写为：

> 视觉基准：深色界面（近黑底、蓝色强调、描边分层）+ 浅色棋盘；正文、次要文字、链接与按钮文字与其背景的对比度均不低于 4.5:1；无装饰性图片与纹理、无渐变。

改写的原因：原句写「灰白为底色」，与本批方向相反。这一句落在需求档，等 M11 的设计评审冻结窗口结束后改，本批次档记一条待办。

## 3. 对比度（按取值算，验收就拿这张表核）

| 前景 | 背景 | 比 | 判定 |
|---|---|---|---|
| `--text` #f9fafb | `--page-bg` #151517 | ≈ 17.4:1 | 过 |
| `--muted` #adb2b8 | `--page-bg` #151517 | ≈ 8.5:1 | 过 |
| `--muted-2` #81858c | `--page-bg` #151517 | ≈ 4.7:1 | 过（余量小，只用于元信息） |
| `--accent` #5686FE | `--page-bg` #151517 | ≈ 5.4:1 | 过（当链接文字用） |
| 白字 `#ffffff` | `--accent-strong` #3f63d8 | ≈ 4.5:1 | 过（填充按钮标签） |
| 白字 | `--accent` #5686FE | ≈ 3.4:1 | **不过**——所以填充按钮不用 `--accent` |
| 棋子红 #b3261e | 棋子面 #fdfcf7 | ≈ 5.7:1 | 过（棋盘未变） |
| 棋子黑 #22262b | 棋子面 #fdfcf7 | ≈ 17:1 | 过 |

`--accent` 与 `--accent-strong` 分工固定：前者只做描边/链接/聚焦环，后者只做填充按钮底。这条分工写进 `base.css` 的注释，免得下次又拿 `--accent` 当按钮底。

## 4. 布局（照 DeepSeek 的比例，不照它的聊天结构）

| 项 | 口径 |
|---|---|
| 顶栏 | 56px 高，深色底 + 底部 1px `--line`；品牌与导航同一行；手机档仍隐品牌名、七项单行（M10 已验证的形态不变） |
| 卡片 | `--panel-bg` + 1px `--line` + `--radius-lg`；不加外投影 |
| 主操作 | 每个视图只有一个填充蓝按钮（对局页的「新局」、棋谱页的「导出」等按现有位置，不新造） |
| 棋盘 | 浅色纸：`--board-bg` + 1px `--line` 描边 + 一圈柔和外投影（深色桌面上这是唯一该有投影的东西——它要被读成「纸」） |
| 间距 | 页内边距 16px、卡片内 16px、控件间距 12px（现有多数为 8–16px，按此对齐即可） |
| 字体 | 沿用现有栈；数字仍 `tabular-nums` |

- 提交门见 `AGENTS.md`。

## 8. 风险

- 深色下棋子与盘线的对比靠「棋盘不变」保住；若有人后来把棋盘也调深，棋子红黑立刻掉到 3:1 以下——这条写进 §2 的固定项。
- `--muted-2` 只有 4.7:1，余量小；它只准用于 12px 以下的元信息，不用于正文或按钮。
- 深色让投影失效；若沿用 `--raise` 的旧值，卡片会糊成一片，所以本批必须同时改 `--raise`，不能只换颜色。
- 只做深色一套：不做 `prefers-color-scheme` 分支、不做主题开关。要浅色版本是另一批的事。
